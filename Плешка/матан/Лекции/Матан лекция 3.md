### Основные теоремы о пределах
1.  если при $x\to a$ $f(x)$ имеет конечный предел равный A,при этом A > p, (A < q) то для значений x достаточно близких к a сама функция удовлетворяет неравенство $f(x) > p ( f(x) < q)$
2. если при $x \to$ a функция $f(x)$ имеет конечное положительный ( отрицательный) $\lim$ то и сама функция положительная (отрицательная) по крайней мере для значений близких к $a$
3.  Если при x \to a функция имеет предел отличный от 0 то покрайней мере для значений x близких к a и сама функция будет отлична от 0
4. Функция f(x) не может одновременно стремиться к 2м различным пределам 
5. если при $x \to R$ $f(x)$ функция имеет конечный предел то для значений x достаточно близких к a функция f(x) будет ограничена
6. Пусть заданы 2 функции $f(x),g(x)$ причем $\lim_{x \to a}f(x) = A$ и $\lim_{x\to a}g(x) = B$
то $f(x)\pm g(x) = A\pm B, f(x)\cdot g(x)=A\cdot B \frac{f(x)}{g(x)} = \frac{A}{B}$

### Сравнение бесконечно малых 
Пусть $\alpha, \beta$ бесконечно малые величины 

#### Определения:

- если отношение $\frac{\alpha}{\beta}(\frac{\beta}{\alpha})$ имеет конечный и отличный от 0 предел при $x \to a$ то эти бесконечные малые величины, называются величинами одного порядка малости 

- если отношение $\frac{\alpha}{\beta}(\frac{\beta}{\alpha})$ стремится к 0  при $x \to a$ то бесконечно малая величина $\alpha$ большей величиной порядка малости чем $\beta$

- будем называть бесконечно малые величины$\alpha$ и $\beta$ эквивалентными, если $\gamma = \alpha - \beta$ оказывается величиной большего порядка малости, чем каждая из величин $\alpha$ и $\beta$
