$$\text{ Автор Енота}$$

### Определения
- Операция * : $x \to y$ называется унарной, если каждому элементу из $x\in X$ ставится в соответствие элемент $y\in Y$ (обозначения $X^*$, $*x$) Примеры унарных операций $A^T, - A$ 
- Операция * : $x \times y \to z$ называется бинарное (обозначается $x * y$) Примеры $A+B$, $AB$, $\lambda A$
- Операция $x * y$ декартово произведение то есть множество пар (x,y) где $x \in X, y \in Y$ 


### Индивидуальные свойства операций
- Инвалютивность $(X^*)^* = X$
- Коммутативность $x*y = y * x$
- Ассоциативность $(A * B) * C = A*(B*C) = A*B*C$

### Взаимодействие операций 
- Дистрибутивность $*$ по &   $(x$ & $y) * z = (x* z)$ & $(y* z)$
- Дистрибутивность * по &     $(x$ & $y)^* = x^*$ & $y ^*$ 
- Ассоциативность $*$ по &    $(x$&$y) * z = x$ & $(y * z) = x$ & $y * z$

### Свойства операций с матрицами 
- Транспонирование инволютивно: $A^{TT} = A$
- Коммутативность: сумма и умножение на число:  $A + B = B + A, \lambda A = A \lambda$
- Ассоциативность: сумма и умножение матриц: $(A + B) + C = A + (B + C), (A B) C = A(BC)$
- Ассоциативно умножение числа на матрицу относительно умножению матрицы и наоборот   $\lambda(\mu A) = (\lambda\mu) A, (\lambda A)B = \lambda (AB)$
- Дистрибутивность: 1. сложение по умножению на число или матрицу    $(A+B)\lambda = \lambda(A + B) = \lambda A + \lambda B, (A + B)C = AC + BC$       2. сумма чисел по умножению на матрицу $(\lambda + \mu) A = \lambda A + \mu A$         3. Транспонирование по сложению $(A + B)^T = A^T + B^T$   Дополнительно $(AB)^T = B^TA^T$

### Определения
  - Элемент e называется нейтральным относительно операции * если $A* e = e * A = A$ для любого $A$. Пример для матриц 0 нейтральный элемент по +, $\cdots E$ нейтральный элемент по * если $AB=BA$
  - Множество & с бинарной операцией $+ (g,h) \to g + h$ называется группой $(G,+)$, если        1. операция ассоциативна   2. $\exists$ нейтральный элемент e    3. $\forall x\in G \ \ \exists$  обратная к элементу $(-x)$                                                                                                                             если операция в группе коммутативна, то группа называется Абелевой 
  - Множество $k$ операциями + и * называется полем $(K, +, * )$, если                                          1. $(K, +)$ Абелева группа (Нейтральный элемент 0)  2.$(K \ \{0\}, * )$ - Абелева группа                3. умножение дистрибутивно относительно сложению: $a*(b + c) = a* b + a * c$
  - Множеством $p(x)$ над полем $K$ называется выражение: $p(x) = \sum^n_{i=1}c_ix^i$ , где $\{c_i\} \subset K, C_n \not = 0  x$ - корень многочлена $p(x)$ если $p(x) = 0$многочлен для которого $n = 2$ называется квадратным $ax^2 + bx + c = 0$
  - Множество  всех корней квадратных уравнений (формально) называется множеством комплексных чисел $-\frac{b \pm \sqrt D}{2a} = e \pm \sqrt f, e,f \in R$ учитывая что $\sqrt {gh} = \sqrt g \sqrt h$ каждое комплексное число представимо в виде $a+ \sqrt{-1}b$ $\sqrt{-1}$ обозначается $i$. Таким образом комплексные числа это числа вида $a + ib$
### Операции
 $z = a + ib, t = u + iv$
 - Умножение $(a + ib)(u + iv) = au + i^2bv + ibu + iav = (au-bv) + (bu + av)i$
 - Сопряжение $\bar{z} = a- ib$
 - модуль $|z| = \sqrt{a^2 + b^2} = \sqrt{z\bar{z}}$
 - Сумма $z + t = (a + u) + i(b + v)$
 - Разность $z -t = (a - u) + i (b - v)$
 - Умножение на число $c(a + ib) = ca + icb$
 - деление при $|t| \not = 0$  $\frac{z}{t} = \frac{z\bar{t}}{|t|^2}$

### Утверждение
Множество комплексных чисел образует поле относительно операций сложения и умножения 

#### Теорема ( основная теорема алгебры )
Многочлен степени n имеет ровно n корней в поле комплексных чисел (C)
$$\sum_{i=0}^n c_ix_i = c\prod^n_{i =1}(x - z_i)$$
где $z_i \in С$
